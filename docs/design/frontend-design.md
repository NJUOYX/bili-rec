## 说明

本文档为**占位文件**，用于在设计目录中预留前端设计的位置。按项目阶段规划，前端设计将在后端主体完成、API 契约稳定后启动（见 `README.md` §阶段规划）。

启动前端阶段时，本文档将至少覆盖：

- 技术栈选型（框架、状态管理、UI 组件库、构建工具，均取当时最新稳定版）。
- 与后端的 API 契约对接（消费后端导出的 OpenAPI，`docs/design/openapi.json`）。
- WebSocket 实时事件/异常的订阅与 UI 刷新机制。
- 页面与组件结构（任务管理、设置管理、关于/状态）。
- 前端测试策略（DT/ST 覆盖）与 CI/CD。

在此之前，请勿基于本文档进行前端开发。
